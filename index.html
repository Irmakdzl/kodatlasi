Sunucu üzerinden açmalısınız

Tarayıcılar file:// protokolünde ES modüllerini (import/export) güvenlik gereği engeller. Proje klasöründe şu komutlardan birini çalıştırın: 

node server.js

Ardından http://localhost:5173 adresini açın. Alternatif olarak VS Code için Live Server eklentisini kullanabilirsiniz.
